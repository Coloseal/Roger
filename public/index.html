    Message history

    Shows the most recent messages on each channel you've joined, so you can listen to what you missed. History is kept on the server, and is cleared when the server restarts or sleeps.

    Settings

    When the channel is busy

    On your phone

    Roger plays a silent sound so Android doesn't put it to sleep, so you'll see a small "Roger is on" media notification. The screen also stays awake while you're in a channel. Turn this off if it gets in the way of other audio.

    When you leave Roger, a round TALK button floats on screen. Hold it to talk. Drag the dots beside it to move it. Android asks you once to allow "Display over other apps".

    While Roger is on screen, hold the volume-down button to talk. (It stops changing the volume.)

    Back only hides Roger and keeps it running. This closes it completely.

    Install

    Add Roger to your home screen so it opens like a normal app.

    Transmit / receive overlay

    Green arrows going right while you talk. Amber arrows going left, with their name, while someone else does. It shows over borderless-window games.

    When I close the window (X)

    Right-click the tray icon (bottom-right of your screen, maybe under the ^ arrow) and choose Quit to exit from there.

    Custom channel keys

    Give any single channel its own key of your choice. All keys work while you're in the game. Mouse buttons can't be used, because Windows security tools flag programs that watch the mouse.

    Hold Space to talk. Install the Roger desktop app to get keys that work while you're in the game.
