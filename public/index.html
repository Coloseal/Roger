    Message history

    Shows the most recent messages on each channel you've joined, so you can listen to what you missed. History is kept on the server, and is cleared when the server restarts or sleeps.

    Transmit / receive overlay

    Green arrows going right while you talk. Amber arrows going left, with their name, while someone else does. It shows over borderless-window games.

    Window

    Updates

    Roger checks for new versions on its own and installs them when you restart it.

    The screens you see load from the server, so most improvements appear without any update.

    Favorite channel hotkeys

    Your channels are numbered 1, 2, 3… (type a number on a channel to move it). Slot 1 gets the first key of the set, slot 2 the second, and so on. Hold a key to talk until you let go, or tap it to stay on air and tap again to release.

    Custom channel keys

    Give any single channel its own key of your choice. All keys work while you're in the game. Mouse buttons can't be used, because Windows security tools flag programs that watch the mouse.

    Hold Space to talk. Install the Roger desktop app to get keys that work while you're in the game.
